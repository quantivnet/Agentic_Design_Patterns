# Format: Teacher Checklist

One printed page. Plain, nontechnical language — the teacher must be able to act on it with no OT background. Define any unavoidable OT term in a short phrase.

Structure:

- **Header:** Student (as given in case data) · Prepared by: School OT (draft)
- **Key Accommodations** — checkbox bullets (`- [ ] item`), one line each, most important first
- **Cueing Hierarchy** — numbered, least-to-most support: what to try first, second, third when the student struggles
- **Materials Needed** — specific items, with specs where relevant
- **When to Contact the OT**
- **Missing Information / Assumptions** — omit only if there are no gaps

No blocking intake requirements; warn if classroom environment or assessment data is missing (accommodations become generic).
