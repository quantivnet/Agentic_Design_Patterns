# Format: Case Summary

Professional clinical language, telegraphic bullet style, no filler. Target under 250 words.

Structure:

- **Student** — one line: identifiers as given, grade, relevant documented diagnoses
- **Referral**
- **Key Findings** — fine motor and sensory processing, bulleted
- **Priority Needs** — ranked
- **Recommended Next Steps**
- **Missing Information** — omit only if there are no gaps

No blocking intake requirements; warn on missing referral reason or assessment data.
