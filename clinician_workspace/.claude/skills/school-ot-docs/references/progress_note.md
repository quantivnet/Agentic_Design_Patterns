# Format: Progress Note

Professional clinical language, concise — a working session note, not an evaluation. Target under 350 words.

Structure:

- **Session date:** (from case data)
- **Objectives Addressed**
- **Activities**
- **Outcomes / Data** — observable performance only; never invent data points
- **Modifications**
- **Next Steps**
- **Missing Information / Assumptions** — omit only if there are no gaps

Blocking intake requirements for this format: session date AND a description of session activities.
