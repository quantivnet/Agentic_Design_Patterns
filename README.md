# Agentic Design Patterns
Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems by Antonio Gulli

## Applications

- [`pediatric_ot_assistant/`](pediatric_ot_assistant/README.md) — a drafting assistant for school-based pediatric occupational therapy documentation (IEP evaluations, progress notes, teacher checklists, parent handouts), built as a four-stage pipeline (intake → redact → generate → review) on the Anthropic API. Install with `pip install -e ".[dev]"`, then see `ot-assist --help`.
